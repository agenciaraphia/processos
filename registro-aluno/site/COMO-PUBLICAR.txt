REGISTRO VIVA CRIANÇA — COMO PUBLICAR NO NETLIFY COM A IA CONECTADA (GEMINI OU CLAUDE)
=====================================================================================

O que tem nesta pasta
- index.html ........................ o site (o modelo do Word já está dentro dele)
- netlify/functions/melhorar.mjs .... a conexão segura com a IA (roda no servidor do Netlify)
- netlify.toml ...................... avisa o Netlify onde está cada coisa

A chave da IA NÃO fica em nenhum arquivo. Ela é cadastrada uma única vez
no painel do Netlify. O navegador da professora nunca vê a chave.

IMPORTANTE: arrastar a pasta no Netlify (Netlify Drop) publica só o index.html,
não publica a função. Use a opção A ou a opção B abaixo.


1) CADASTRAR A CHAVE (uma vez só)
---------------------------------
Funciona com Gemini (Google) ou com Claude (Anthropic). Cadastre UMA das chaves.

No Netlify, abra o seu site > Site configuration > Environment variables > Add a variable.
Em cada variável: deixe "Contains secret values" DESMARCADO (no plano gratuito ele trava o
"All scopes"), escolha "All scopes" e "Same value for all deploy contexts".

  GEMINI_API_KEY    = sua chave do Gemini (crie em https://aistudio.google.com/apikey)
      ou
  ANTHROPIC_API_KEY = sua chave do Claude (crie em https://console.anthropic.com/settings/keys)

  APP_SENHA         = uma senha simples da escola, ex.: jardim2026   (recomendado)
                      Sem ela, qualquer pessoa que tiver o link pode usar a sua chave.

  Opcionais: IA (gemini ou claude, se cadastrar as duas chaves),
             GEMINI_MODEL (padrão gemini-3.8-flash), CLAUDE_MODEL (padrão claude-sonnet-5-5)

A chave continua só no Netlify: ela nunca vai para o HTML nem para o navegador.


2A) PUBLICAR PELO GITHUB (sem usar terminal) — recomendado
-----------------------------------------------------------
1. Coloque esta pasta num repositório do GitHub (pode ser o agenciaraphia/processos,
   onde ela já está em registro-aluno/site).
2. No Netlify, abra o site > Site configuration > Build & deploy > Continuous deployment
   > Link repository (ou crie um site novo em Add new site > Import an existing project).
3. Escolha o repositório e preencha:
     Branch to deploy:   a branch onde a pasta está (ex.: main)
     Base directory:     registro-aluno/site      (ou deixe vazio se a pasta for a raiz do repositório)
     Build command:      (deixe vazio, o netlify.toml já resolve)
     Publish directory:  registro-aluno/site      (ou . se for a raiz)
4. Clique em Deploy. A cada mudança no GitHub o site atualiza sozinho.


2B) PUBLICAR PELO TERMINAL (Netlify CLI)
---------------------------------------
No computador (precisa do Node.js instalado), dentro desta pasta:

  npx netlify-cli login
  npx netlify-cli link          (escolha o site que você já criou)
  npx netlify-cli deploy --prod


3) CONFERIR
-----------
- Depois de cadastrar a chave, publique de novo (Deploys > Trigger deploy) para ela valer.
- Abra o site: no passo 3 deve aparecer "Gemini conectado ao site" (ou "Claude conectado ao site").
- Na primeira vez em cada aparelho, a página pede a senha da escola (APP_SENHA). Só uma vez.
- Se aparecer "falta cadastrar a chave", confira o passo 1 e publique de novo.

MICROFONE
- Abra pelo endereço https:// do site, no Chrome (computador/Android) ou Safari (iPhone).
- Quando o navegador perguntar, escolha PERMITIR. Se bloquear, a página mostra como liberar.
- Alternativa que sempre funciona: microfone do teclado do celular na caixa de texto.

QUER GASTAR ZERO? (Gemini gratuito)
- Use a chave do Gemini no plano gratuito (GEMINI_API_KEY) e o plano gratuito do Netlify.
- O site já troca o nome da criança e dos pais por [NOME], [PAI] e [MAE] antes de enviar
  o relato para a IA, e coloca os nomes de volta quando o texto chega.
- Cuidado: no plano gratuito o Google pode usar o relato para melhorar os produtos dele.
  Por isso, preencha o NOME DA CRIANÇA no passo 1 antes de tocar em "Melhorar o texto" e
  evite falar nome e sobrenome de OUTRAS crianças no relato (esses o site não reconhece).
